# 02 · Term expansion strategies by language pair

Compares the same term-expansion strategies as [`01_term_expansion_by_model`](../01_term_expansion_by_model/README.md) (original / GPT contextual expand / GPT domain-filtered clean, plus no_term, random_term, and external dictionary), broken out per language pair rather than aggregated. Produces the poster's `fig_expansion_strategies` figure.

This is a **thin wrapper**: no experiment-local data, only this experiment's `scripts/` and `report/` below. It reads the same shared `data/` → `results/` pipeline as `01_term_expansion_by_model` from a different angle (per-language rather than macro-averaged).

## Reproduce

```bash
python src/analysis/generate_result_figures.py --only mode_comparison
```

Generating script: [`scripts/figure_mode_comparison.py`](scripts/figure_mode_comparison.py) (`build_mode_comparison_figure`), shared helpers in [`src/analysis/figure_common.py`](../../src/analysis/figure_common.py) and [`src/analysis/metrics_loader.py`](../../src/analysis/metrics_loader.py).

## Inputs

Same `results/dev_v1/{original,expand,cleaned,dictionary}/gpt/metrics_summary.json` files as `01_term_expansion_by_model` — see that experiment's table for the full source-data → results-path mapping.

## Output

[`poster/figures/fig_expansion_strategies.pdf`](../../poster/figures/fig_expansion_strategies.pdf)
