# Term expansion strategies by language pair

Compares the same term-expansion strategies as [`term_expansion/by_model`](../by_model/README.md) (original / GPT contextual expand / GPT domain-filtered clean, plus no_term, random_term, and external dictionary), broken out per language pair rather than aggregated. Produces the poster's `fig_expansion_strategies` figure.

This is a **thin wrapper**: no experiment-local data, only this experiment's `scripts/` and `report/` below. It reads the same shared `data/` → `results/` pipeline as `term_expansion/by_model` from a different angle (per-language rather than macro-averaged).

## Reproduce

```bash
python src/analysis/generate_result_figures.py --only mode_comparison
```

Generating script: [`scripts/figure_mode_comparison.py`](scripts/figure_mode_comparison.py) (`build_mode_comparison_figure`), shared helpers in [`src/analysis/figure_common.py`](../../../src/analysis/figure_common.py) and [`src/analysis/metrics_loader.py`](../../../src/analysis/metrics_loader.py).

## Inputs

Same `results/dev_v1/{original/zero_shot,expand,cleaned,dictionary}/gpt/metrics_summary.json` files as `term_expansion/by_model` — see that experiment's table for the full source-data → results-path mapping.

## Output

[`figures/fig_expansion_strategies.pdf`](figures/fig_expansion_strategies.pdf) — this is the figure's home; it's copied to [`poster/figures/`](../../../poster/figures/fig_expansion_strategies.pdf) for the poster.

## Report tables

Language-pair comparison (`ende` / `enru` / `enes`) workbook, one sheet per dataset variant, rows grouped by mode (`no_term` / `proper_term` / `random_term`) then model, generated by [`scripts/compare_languages_to_excel.py`](scripts/compare_languages_to_excel.py):

**Note:** `no_term`/`random_term` results only exist under `results/dev_v1/original/few_shot/` -- they were pruned from `zero_shot`/`expand`/`cleaned`/`dictionary` as redundant (those modes don't depend on the term-list variant). `compare_languages_to_excel.py` handles this correctly: the other variant sheets simply show `proper_term` rows only (no `no_term`/`random_term` rows), and the mode-label merge is computed from the actual rows present so the layout doesn't break when a mode has zero rows.
